Product

What’s in Spawn

A private app builder that runs on your machine. Real files, a live preview, chat to change them, then a public URL — domains and secrets included.

Get early access See how it works

Included

Everything you need to go from idea to a live site without leaving the builder.

  • Create

    Start an app

    Describe what you’re building or open files already on your machine. Spawn scaffolds a real project — not a throwaway sandbox.

  • Run

    Local preview

    Hit Run and see the app live on localhost. You’re looking at the real process on your machine — no deploy required to try a change.

  • Build chat

    Change it in English

    Ask for a pricing table, auth flow, or layout fix. Spawn edits the files, shows the diff, and refreshes the preview.

  • Go Live

    Public URL

    Publish a real HTTPS link. Share it, point traffic at it, keep iterating — without switching tools to ship.

  • Domains

    Your hostname

    Attach a custom domain from inside Spawn. Apex and www stay wired to your live app — no separate hosting console.

  • Secrets

    Keys stay put

    Store API keys and env vars in Secrets. They’re injected at run and deploy time — they don’t live in your source tree.

  • Evolve

    Keep shipping

    After Go Live, keep building. Chat in a change, re-run, republish. The same loop — create → run → build → live — doesn’t stop at v1.

  • Local AI

    On your machine

    Build chat and product help run with your keys, against your project. Your code stays local until you choose to publish.

The loop

One surface. Four moves. Ship without leaving Spawn.

  1. 01 Create Scaffold or open files
  2. 02 Run Preview on localhost
  3. 03 Build Chat a change, see the diff
  4. 04 Go Live Public URL + domain + secrets
