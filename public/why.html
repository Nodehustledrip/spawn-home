Because the app should live on your machine — then on the internet.

Spawn is a private app builder: real files on your computer, a localhost preview, Build chat to change them, then Go Live for a public HTTPS URL. Domains, secrets, and plugins stay in the same product.

What most builders leave out

Generic chat-to-app tools often stop at a temporary preview or a disposable export. Spawn is built for the full loop — private work, then a URL you’d put your name on.

Machine

Your computer, not a rented tab

Source, uncommitted work, and secrets stay on your machine until you publish. Open the files, read the diff, keep the repo — nothing important lives only inside a browser session.

URL

A real public site

Go Live publishes HTTPS that stays up. Attach your domain. Share a link that doesn’t vanish when the tab closes — the same app you ran on localhost.

Chat

Build chat on real files

Ask in English; Spawn edits the project, shows the diff, and refreshes the preview. Iteration is the product — not a one-shot dump of code you can’t keep evolving.

Ship kit

Domains, secrets, plugins — here

Custom hostname, env injection, and extensions live inside Spawn. You don’t bounce across hosting consoles just to finish shipping.

Six principles

The bar we build to — complementary to Product and How, not a second feature list.

  1. 01

    Build on your machine

    Local-first, not cloud-only.

    The project is files. Diff them, commit them, keep them. The builder doesn’t own your source.

  2. 02

    Run it locally

    The real process, not a mock.

    Hit Run. Preview is localhost — the same app you’ll ship. Deploy stays optional until you’re ready.

  3. 03

    Ship a real URL

    On the internet, not a session.

    Go Live publishes HTTPS. Point a custom domain. Share a link that stays live while you keep iterating.

  4. 04

    Code and secrets stay yours

    You own the machine.

    Source stays local until you publish. Keys live in Secrets and inject at run and deploy — not in a workspace you don’t control.

  5. 05

    Evolve continuously

    v1 is not the finish.

    Chat a change, re-run, republish. The same loop keeps moving after the first URL is live.

  6. 06

    A premium bar, not a demo

    Software you’d put your name on.

    Structure, diffs, a live site. Spawn is for products you’d ship — not a throwaway mock.

Who it’s for

  • You want the files A project on your computer. Open it, diff it, keep it.
  • You’re putting a name on it A public URL and a domain — work you’d actually share.
  • You’ll keep going Change, run, and publish again after the first link is live.
